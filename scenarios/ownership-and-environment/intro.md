# Welcome to Week 2 • Session II Lab! 🐧

Welcome to the interactive terminal practical for **Week 2: Packages, Permissions & Environment Variables (Session II)**!

### What You Will Build & Master:
1. **File & Directory Ownership**:
   - Transfer ownership using `chown` and `chgrp`.
   - Apply ownership recursively across directory trees with `-R`.
   - Understand why modifying user ownership requires `sudo` superuser rights.
2. **Environment Variables**:
   - Inspect standard system variables: `$USER`, `$HOME`, `$SHELL`, and `$PATH`.
   - Differentiate between local variables and child process visibility with `export`.
   - Inspect all active environment variables using `printenv`.
3. **Persistent Shell Customization**:
   - Permanently save custom environment variables inside `~/.bashrc`.
   - Extend `$PATH` to include a personal script repository (`$HOME/scripts`).
   - Reload shell configuration into your live session with `source ~/.bashrc`.
4. **Terminal Text Editing**:
   - Author configuration files in **Nano** (`Ctrl+O` save, `Ctrl+X` exit).
   - Navigate **Vim modal editing**: Normal mode, Insert mode (`i`), Command mode (`:wq`, `:q!`), line deletion (`dd`), and undo (`u`).
