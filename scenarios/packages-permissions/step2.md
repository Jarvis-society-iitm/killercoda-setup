# Step 2: Package Management with APT

In Session 2, we learned how to search, inspect, and install packages using Debian/Ubuntu `apt`.

### Task:
1. Use `apt` to install both `htop` (interactive process viewer) and `tree` (recursive directory tree visualizer):
   ```bash
   apt-get install -y htop tree
   ```
2. Verify that both binaries are present in `/usr/bin/`:
   ```bash
   which htop
   which tree
   ```

Click **Verify** once both packages are installed.
