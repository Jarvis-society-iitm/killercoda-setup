# Week 1, Session II: Diagnostics, Data Streams & Pipelines

Welcome back, Systems Specialist!

In **Session I**, you learned how to navigate the filesystem (`pwd`, `ls`, `cd`, `tree`), create and manipulate files (`touch`, `mkdir`, `cp`, `mv`), and read or inspect data (`cat`, `less`, `head`, `tail`).

In **Session II**, you will master:
1. **System Diagnostics**: Inspect kernel identity, uptime, CPU cores, block storage devices, filesystem storage, and available RAM (`uname`, `uptime`, `lscpu`, `lsblk`, `df -h`, `free -h`).
2. **File Descriptors & Data Redirection**: Understand streams (`stdin` [FD 0], `stdout` [FD 1], `stderr` [FD 2]), overwriting with `>`, appending with `>>`, reading with `<`, isolating errors with `2>`, and combining streams with `2>&1`.
3. **Pipes (`|`)**: Route stdout from one tool directly into stdin of another to build powerful command pipelines.
4. **Linux Manuals**: Navigate `man`, `--help`, and `tldr`.
5. **Synthesis Challenge**: Assemble the multi-tier `system_specs.txt` diagnostic dossier and preview your Weekly Challenge (`system_snapshot.txt`).
