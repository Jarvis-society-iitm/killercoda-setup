# Step 1: Club Authentication & Verification

Before running diagnostics, your terminal environment must be authenticated with the Jarvis Linux Club backend.

### Task:
1. Complete the prompt on the terminal to the right:
   - **Student ID**: Enter your roll number (e.g. `25f3002130`).
   - **Passkey**: Enter your secure passkey from your club dashboard (`~/labs`).
2. If your prompt did not open automatically or you need to inspect your authentication state:
   ```bash
   club-gate status
   ```
3. Test your system identity command as covered in Slide 3:
   ```bash
   uname -a
   ```
   *Identify your kernel name, hostname, kernel release version, and machine architecture.*

Click **Verify** below once authenticated to unlock Step 2!
